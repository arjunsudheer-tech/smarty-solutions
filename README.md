# 💼 Smarty Solutions — Business Website

A modern business landing page built using **HTML5** and **CSS3**. This project was created from scratch to practice building a complete business website with multiple sections, responsive layouts, reusable styling and modern UI design.

## 📸 Preview

---

## 🚀 Live Demo

## ✨ Features

* Modern business landing page design
* Responsive navigation header
* Hero section with call to action buttons
* Services section with responsive card layout
* Business benefits section with alternating image and content layouts
* Team members section
* Newsletter subscription section
* Responsive design for different screen sizes
* Organized CSS using separate files for different sections
* Smooth scrolling navigation

---

## 🛠️ Built With

* HTML5
* CSS3

## 🎯 What I Learned

While building this project, I practiced:

* Structuring a complete website using semantic HTML
* Creating responsive layouts using CSS Grid and Flexbox
* Designing hero sections and call to action elements
* Creating reusable CSS styles for different website sections
* Working with images and responsive image layouts
* Using media queries to make the website responsive
* Organizing CSS into multiple files for better maintainability
* Creating smooth scrolling navigation between sections
* Improving spacing, typography and visual hierarchy

---

## 📱 Responsive Design

The website adapts to smaller screen sizes using CSS media queries.

The responsive layout includes:

* Single-column service layout on smaller screens
* Responsive benefit sections
* Two-column team layout on mobile
* Responsive newsletter form
* Flexible content containers
